## 📖 Course Overview

This is a complete, hands-on JavaScript course built for people who are starting **from zero** — even if this is your first programming language.

In four hours, you'll go from core fundamentals to modern, advanced JavaScript (ES6+), with a practice exercise after every topic and one real project tying it all together: a **Currency Converter** built from scratch using the Fetch API.

No fluff, no filler — just clear explanations, live coding, and a project you can actually show off.

---

## 🗂️ What You'll Learn

**Foundations**
`Variables` · `Data Types` · `Operators` · `Conditionals` · `Loops` · `Functions` · `Arrays` · `Objects` · `DOM & Events`

**Modern JavaScript (ES6+)**
`Variable Scoping` · `Closures` · `Arrow Functions` · `Default / Rest / Spread Parameters` · `Template Literals` · `Destructuring` · `Ternary Operator` · `Enhanced Object Literals` · `Array Methods` · `Higher-Order & Callback Functions` · `Iterators & Generators` · `Optional Chaining`

**Advanced Concepts**
`The "this" Keyword` · `call / apply / bind` · `Callbacks vs. Promises vs. Async/Await` · `API Integration with Fetch`

**Real Project**
A fully functional **Currency Converter** — custom dropdowns, live exchange rates, and dynamic UI updates, built line by line.
